# مجتمع دروب | Droob Community CRM

نظام متكامل لإدارة مجتمعات ريادة الأعمال والاستثمار — مبني بتصميم احترافي داكن (Dark Glassmorphism) ودعم كامل للعربية.

---

## الملفات الرئيسية

| الملف | الدور |
|---|---|
| `portal.html` | بوابة الأعضاء العامة |
| `index.html` | لوحة تحكم الأدمن (CRM) |
| `google-apps-script.js` | سكريبت الربط مع Google Sheets |
| `server.js` | Express server (Node.js) |

---

## المزايا

### بوابة الأعضاء (`portal.html`)
- تسجيل عضوية جديدة (مستثمر / رائد أعمال)
- معرض الفعاليات + تأكيد الحضور
- دليل الأعضاء مع البحث والتصفية
- **🆕 نشرة بريدية** — اشتراك مع تأكيد إيميل تلقائي
- **🆕 تواصل معنا** — زر عائم يفتح نموذج تواصل
- **🆕 سجل اهتمامك** — نموذج لتسجيل نوع الاهتمام (استثمار / تمويل / شراكة)

### لوحة التحكم (`index.html`)
- إدارة الأعضاء (CRM) مع تقييم التفاعل
- إدارة الفعاليات + أتمتة الدعوات بالإيميل
- استيراد CSV من Google Forms
- محاكي البريد الإلكتروني
- **🆕 إدارة مشتركي النشرة البريدية**
- **🆕 رسائل التواصل** مع حالة مقروء/غير مقروء
- **🆕 طلبات الاهتمام** مع تحويلها لأعضاء مباشرة

## ربط Google Sheets

### 1. إعداد Apps Script
1. افتح Google Sheet الخاص بك
2. **Extensions → Apps Script**
3. انسخ محتوى `google-apps-script.js` كاملاً والصقه
4. شغّل دالة **`setup()`** — تضيف تلقائياً هذه الشيتات:

| الشيت | المحتوى |
|---|---|
| `Members` | بيانات الأعضاء |
| `Events` | الفعاليات |
| `Invitations` | الدعوات وحالة الحضور |
| `Newsletter` | مشتركو النشرة البريدية |
| `ContactMessages` | رسائل التواصل |
| `InterestRegistrations` | طلبات الاهتمام |

5. **Deploy → New Deployment → Web App**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. انسخ رابط الـ Web App

### 2. ربط البوابة بالشيت

**الطريقة الأولى — رابط مباشر:**
```
portal.html?api=PASTE_YOUR_WEB_APP_URL_HERE
```

**الطريقة الثانية — يدوي:**
افتح البوابة ← أيقونة الترس (Settings) ← الصق الرابط ← حفظ
